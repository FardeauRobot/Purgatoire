# Back Track King — game statement

CodinGame Summer Challenge 2026. Two players paint railway tracks on a
magic map to connect towns, and disrupt regions to wash away each other's
tracks.

Official referee source: <https://github.com/CGjupoulton/SummerChallenge2026>

---

## Leagues

The game is league-based. In the first two leagues you only fight a boss, and
you advance by winning 3 games out of 5. In those leagues the full game runs,
but the **only** way to win is to complete the league objective.

### League 1 — connect

Form one active connection between two towns and score at least one point.
You win instantly. The boss does nothing (WAIT every turn). If you haven't
done it after 100 turns, you lose.

### League 2 — disrupt

Use `DISRUPT` to ink out a region that contains at least one enemy track. The
boss places tracks between random towns. If you haven't done it after 100
turns, you lose.

### League 3 and above — full game

Have more points than your opponent after 100 turns. The game also ends early
if no desired connection can be made any more; whoever leads then wins.

---

## Map

The map is a grid of `width × height` cells (21 ≤ width ≤ 30,
14 ≤ height ≤ 20). Each cell has a terrain type:

| Type | Terrain  | Track cost |
| ---- | -------- | ---------- |
| 0    | plains   | 1          |
| 1    | river    | 2          |
| 2    | mountain | 3          |

The grid is split into **regions**: groups of adjacent cells, each with a
`regionId`. Regions can be disrupted.

### Towns

Between 4 and 12 towns sit on plains cells, each with a `townId`. A region
holds at most one town, and two neighbouring regions never both hold one.

Each town has a list of **desired connections**: ids of the towns it wants a
railway to. The wish goes one way only: if town 0 wants town 1, town 1
doesn't automatically want town 0. A town may want nothing, but every town is
wanted by at least one other town.

---

## Placing tracks

Each turn a player has **3 paint points**. Unused points are lost at the end
of the turn.

- Placing a track costs the terrain cost of its cell (1 / 2 / 3).
- A track belongs to the player who placed it (`0` or `1`).
- If both players place a track on the same cell in the same turn, the track
  is **neutral** (owner `2`).
- You can't place a track on a town, on an existing track or in an inked
  region.
- Tracks link up automatically with orthogonally adjacent tracks and towns.

---

## Connections and scoring

For every pair (town A, town B) where A wants B: if a path exists, the
**shortest** path becomes the **active connection** A→B. A path is a chain
of orthogonally adjacent cells, each holding a track or a town. Any owner's
track counts, neutral ones included.

When several shortest paths exist, the one chosen from A towards B tries
directions in the order **NORTH, EAST, SOUTH, WEST**.

At the end of every turn, each active connection gives each player **1 point
per track they own on its path**. Neutral tracks score for nobody. A track on
several active paths scores once for each of them.

---

## Disruption

Each turn a player also has **1 disruption point** (it doesn't carry over
either). Spending it on a region raises that region's **instability** by 1.

When a region's instability reaches **4**, the region is **inked out**:

- every track in it is removed,
- nobody can place a track there any more,
- every active connection through it breaks.

You can't disrupt a region that is already inked, or a region with a town.

---

## Actions

Each turn, print **one line** with at least one action. Separate actions with
`;`.

| Action                | Effect                                                               |
| --------------------- | -------------------------------------------------------------------- |
| `PLACE_TRACKS x y`    | Place a track on (x, y).                                             |
| `AUTOPLACE x1 y1 x2 y2` | Place the cheapest chain of tracks from (x1,y1) to (x2,y2), as far as the paint allows. **At most one per turn.** |
| `DISRUPT regionId`    | Raise that region's instability by 1.                                |
| `DISRUPT x y`         | Same, for the region containing (x, y).                              |
| `MESSAGE text`        | Show text in the viewer.                                             |
| `WAIT`                | Do nothing.                                                          |

Example: `AUTOPLACE 3 4 12 9;DISRUPT 17;MESSAGE choo choo`

### Order within a turn

1. Every `PLACE_TRACKS`, including those generated by `AUTOPLACE`, player 0's
   then player 1's (conflicts on the same cell become neutral).
2. Every `DISRUPT`.
3. Regions at instability ≥ 4 are inked out.
4. Connections are recomputed and points are scored.

An action that is impossible (not enough paint, occupied cell…) is skipped;
the other actions still happen. If an `AUTOPLACE` runs out of paint, the
rest of its tracks are skipped.

### Losing

- No line in time, or a line that isn't valid syntax → you're out.
- Leagues 1 and 2: objective not reached after 100 turns.

## Protocol

### Initialization input

```
myId                         0 or 1
width
height
width*height lines:          regionId type          (left→right, top→bottom)
townCount
townCount lines:             townId townX townY desiredConnections
```

`desiredConnections` is a comma-separated list of town ids (`1,2,4`), or `x`
if there are none.

### Input for each turn

```
myScore
foeScore
width*height lines:          trackOwner instability inked partOfActiveConnections
```

- `trackOwner`: `-1` no track, `0` / `1` player, `2` neutral.
- `instability`: instability of the cell's region.
- `inked`: `1` if the region is inked out, else `0`.
- `partOfActiveConnections`: the connections whose path uses this cell, as
  `from-to` pairs separated by commas (`1-2,1-3,4-7`), or `x`.

### Output

One line: actions separated by `;`, with at most one `AUTOPLACE`.

### Constraints

- First turn: ≤ 1000 ms. Each later turn: ≤ 50 ms.
- 21 ≤ width ≤ 30, 14 ≤ height ≤ 20, 4 ≤ townCount ≤ 12.
